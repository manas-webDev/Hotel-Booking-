# Stayora

Stayora is a luxury hotel booking web application providing a seamless experience for travelers to discover handpicked destinations, explore room details, filter by price and room type, and manage hotel reservations. It also includes an intuitive hotel owner management portal for listing and tracking rooms and revenue.

## Tech Stack

- **Framework**: React 19, Vite
- **Styling**: Tailwind CSS v4 (via `@tailwindcss/vite`)
- **Routing**: react-router-dom v7
- **Authentication**: Clerk (`@clerk/react`)

## Getting Started

1. **Install dependencies**:
   ```bash
   npm install
   ```

2. **Configure environment variables**:
   Create a `.env` file from `.env.example`:
   ```bash
   VITE_CLERK_PUBLISHABLE_KEY=your_publishable_key_here
   ```

3. **Start the development server**:
   ```bash
   npm run dev
   ```
